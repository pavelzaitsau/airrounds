# T0 toolchains and test builds

We verified both toolchains on macOS arm64 on November 18, 2026. Tools live in
`.airrounds-tools/` and build outputs in `artifacts/t0/`. Both programs under
`tests/toolchain/` run without the radio. Run the commands from the repository
root.

| Component | Verified versions |
| --- | --- |
| ESP32-S2 | Arduino CLI 1.6.0, Arduino ESP32 core 2.0.11, Xtensa GCC 8.4.0 (esp-2021r2-patch5), Python esptool 4.5.1 |
| Flipper Zero | ufbt 0.2.6, official SDK f7 1.5.1 (API 88.2), Flipper toolchain 39, ARM GCC 12.3.1 (20230626) |
| Build Python | CPython 3.12.15 through uv 0.13.8 |

## ESP32-S2

Use the official Arduino CLI archive and the Espressif index.

```sh
root="$PWD"
esp="$root/.airrounds-tools/arduino"
mkdir -p "$esp/bin"
archive="$esp/arduino-cli_1.6.0_macOS_ARM64.tar.gz"
curl -fsSL -o "$archive" \
  https://github.com/arduino/arduino-cli/releases/download/v1.6.0/arduino-cli_1.6.0_macOS_ARM64.tar.gz
printf 'dc70f037fcbc8e7add892282bed5bab5eac317ff00bf0dd2f21e4a8e1d338a1c  %s\n' "$archive" | shasum -a 256 -c
tar -xzf "$archive" -C "$esp/bin" arduino-cli
export ARDUINO_DIRECTORIES_DATA="$esp/data"
export ARDUINO_DIRECTORIES_DOWNLOADS="$esp/downloads"
export ARDUINO_DIRECTORIES_USER="$esp/user"
index=https://espressif.github.io/arduino-esp32/package_esp32_index.json
"$esp/bin/arduino-cli" core update-index --additional-urls "$index"
"$esp/bin/arduino-cli" core install esp32:esp32@2.0.11 --additional-urls "$index"
UV_CACHE_DIR="$esp/uv-cache" uv venv --python 3.12.15 "$esp/venv"
UV_CACHE_DIR="$esp/uv-cache" uv pip install --python "$esp/venv/bin/python" esptool==4.5.1
```

The bundled Xtensa GCC runs on arm64. The `esptool` binary in core 2.0.11
targets Intel Macs. Use the same version from the Python environment to build
without Rosetta or SDK changes.

```sh
mkdir -p artifacts/t0/esp32
PATH="$esp/venv/bin:$PATH" "$esp/bin/arduino-cli" compile \
  --fqbn esp32:esp32:esp32s2 \
  --build-property "tools.esptool_py.path=$esp/venv/bin" \
  --build-property tools.esptool_py.cmd=esptool.py \
  --output-dir artifacts/t0/esp32 tests/toolchain/esp32/airrounds_smoke
"$esp/venv/bin/esptool.py" --chip esp32s2 image_info \
  artifacts/t0/esp32/airrounds_smoke.ino.bin
```

## Flipper Zero

This section records the T0 SDK and smoke build. For the current app, use
the [AirRounds build steps](../flipper/README.md#build-and-connect).

Install the f7 SDK from the verified archive. On the first build, ufbt
downloads the ARM toolchain for macOS arm64.

```sh
root="$PWD"
flipper="$root/.airrounds-tools/flipper"
mkdir -p "$flipper"
export UFBT_HOME="$flipper/ufbt"
UV_CACHE_DIR="$flipper/uv-cache" uv venv --python 3.12.15 "$flipper/venv"
UV_CACHE_DIR="$flipper/uv-cache" uv pip install --python "$flipper/venv/bin/python" ufbt==0.2.6
archive="$flipper/flipper-z-f7-sdk-1.5.1.zip"
curl -fsSL -o "$archive" \
  https://update.flipperzero.one/builds/firmware/1.5.1/flipper-z-f7-sdk-1.5.1.zip
printf 'dfde39df32ba8a9789b26afc1d702579ad8399a1c285770637cfe3287b2e2ffe  %s\n' "$archive" | shasum -a 256 -c
"$flipper/venv/bin/ufbt" update --hw-target f7 --local "$archive"
```

```sh
mkdir -p artifacts/t0/flipper
(cd tests/toolchain/flipper && "$flipper/venv/bin/ufbt")
cp tests/toolchain/flipper/dist/airrounds_smoke.fap artifacts/t0/flipper/
"$UFBT_HOME/toolchain/arm64-darwin/bin/arm-none-eabi-readelf" \
  -h -SW artifacts/t0/flipper/airrounds_smoke.fap
```
